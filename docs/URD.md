# URD · 知识产权代理 CRM 系统（Idea Brief）

> 项目：ip-crm ｜ 强度：standard（含 strict 补充：费用/删除/期限安全）
> 范围：商标 + 版权代理业务（不含专利）

## 1. 目标用户与角色

- **URD-ROLE-001** 代理人：单人使用，创建客户/案件/流程/费用/期限，管理系统数据。需账号密码登录，无多角色。

## 2. 项目目标

- **URD-GOAL-001** 让一个人也能把商标/版权代理业务管清楚：客户、案件、流程节点、费用、期限五件事在一个界面里完成，不丢单、不误期限、不糊涂账。

## 3. 功能需求（已确认）

### 客户管理
- **URD-REQ-001** 客户增删改查：姓名、公司、电话、邮箱、备注。
- **URD-REQ-002** 删除客户前必须确认；删除客户时提示其名下案件数。

### 案件管理
- **URD-REQ-003** 案件分两大类型：商标、版权。
- **URD-REQ-004** 商标子类：注册申请、驳回复审、异议、无效宣告、续展、变更、转让。
- **URD-REQ-005** 版权子类：作品登记、变更、撤销。
- **URD-REQ-006** 案件字段：所属客户、类型/子类、案件名称（商标名/作品名）、申请号、申请日、状态、当前阶段、备注。
- **URD-REQ-007** 案件状态：进行中 / 已完成 / 已终止（含驳回、放弃等）。
- **URD-REQ-008** 案件流程节点记录：可添加/查看节点历史（时间线），如"提交-受理-审查-初审公告-注册"。
- **URD-REQ-009** 案件可按类型、状态、客户、关键字筛选检索。

### 费用管理
- **URD-REQ-010** 每个案件可挂多笔费用，分**官费**与**代理费**两类。
- **URD-REQ-011** 每笔费用含：费用名称、金额（应收）、缴费期限、备注，以及**到账明细列表**。
- **URD-REQ-012** 支持登记收款：每笔到账单独记录；实收金额 = Σ 到账明细；状态自动计算（无到账=未收，实收<应收=部分，实收≥应收=已收）。
- **URD-REQ-013** 全局对账：总应收、总实收、待收汇总。

### 期限提醒
- **URD-REQ-014** 三类期限：商标续展（注册日+10年，提前 1 年提醒）、官方答复期限、费用缴纳期限。
- **URD-REQ-015** 每案可手动登记期限提醒：标题、类型、到期日。
- **URD-REQ-016** 期限支持标记完成；到期/临近到期有可视化预警。

### 看板
- **URD-REQ-017** 看板汇总：案件总数（按类型/状态）、费用应收/实收、30 天内到期提醒列表。

### 登录认证
- **URD-REQ-018** 系统需登录后使用；默认账号 `alimjan` / 密码 `alimjan580`。
- **URD-REQ-019** 登录态用 Session Cookie 维持；未登录访问业务 API 返回 401。
- **URD-REQ-020** 支持退出登录；凭证可通过环境变量 `IPCRM_USERNAME` / `IPCRM_PASSWORD` 覆盖。

## 4. 成功标准（可度量）

- **URD-AC-001** 可在 30 秒内完成一个案件 + 客户 + 首笔费用的录入。
- **URD-AC-002** 所有业务数据（客户/案件/节点/费用/期限）支持增删改查，删除有确认。
- **URD-AC-003** 30 天内到期的期限一定出现在看板提醒区。
- **URD-AC-004** 数据持久化（Deno KV），刷新/重启不丢失。
- **URD-AC-005** 部署到 Deno Deploy 后通过公网 URL 可访问。
- **URD-AC-006** 未登录访问业务 API 被拒绝（401）；用正确凭证可登录并持久会话。

## 5. 明确排除（Out of Scope）

- **专利业务**：本次明确不包含。
- 多用户登录、权限、操作审计日志。
- 邮件/短信自动提醒（仅系统内提醒）。
- 商标查询/近似检索等外部数据服务对接。
- 官费实时汇率/缴费渠道对接。
- 数据导出/报表打印。
- 附件上传、文档生成。

## 6. 主要约束

- **URD-CON-001** 技术栈固定：Deno 2.x + Hono + Deno KV，前端原生 HTML/CSS/JS 零构建（与现 CRM 一致）。
- **URD-CON-002** 部署目标：Deno Deploy 免费计划。
- **URD-CON-003** 单用户账号密码登录，界面为桌面浏览器单页应用。
- **URD-CON-004** 数据隐私：客户姓名/电话/邮箱属个人信息，本地与云端 KV 持久化，不做公开接口暴露。
- **URD-CON-005** 凭证安全：默认账号写入代码便于开箱即用，推荐部署时用环境变量覆盖；Session 采用 HttpOnly Cookie + 随机 token，有效期 7 天。

## 7. 假设与开放问题

### 已确认假设
- **URD-ASM-001** 案件总量在个人代理所规模（千级以内），无需分页索引优化，KV 全量扫描可接受。
- **URD-ASM-002** 流程节点用"阶段文本 + 记录"的轻量模型，不引入复杂状态机。
- **URD-ASM-003** 币种人民币，金额存数字（分）。

### 已确认决策（曾为开放问题）
- **URD-DEC-001** 部分收款：记录每笔到账明细，实收自动汇总（对应 REQ-012）。
- **URD-DEC-002** 初始数据：从空库开始，不预置演示数据。

### 开放问题
- 暂无。

## 8. 术语
- 官费：官方收取的费用（如商标注册规费、版权登记费）。
- 代理费：代理机构收取的服务费。
- 状态流转：案件在当前阶段推进时逐条新增节点记录，不改动历史。
